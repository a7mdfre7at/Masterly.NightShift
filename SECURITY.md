# Security Policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue. Use GitHub's private reporting:
<https://github.com/a7mdfre7at/Masterly.NightShift/security/advisories/new>

Include what you found, how to reproduce it, and which versions are affected. You will get a reply as soon as possible. Please allow time for a fix and a release before you disclose the problem publicly.

## Supported versions

Fixes go into the latest release.
