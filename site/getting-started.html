Get started

Install Masterly.NightShift, set up an ASP.NET Core or console host, enqueue fire-and-forget, delayed, recurring and continuation jobs, and open the dashboard.

Install

The Masterly.NightShift meta package brings in the core, SQL Server storage and ASP.NET Core packages. Or pick the pieces you need:

dotnet add package Masterly.NightShift
PackageWhat it is
Masterly.NightShiftMeta package: Core, SqlServer and AspNetCore.
Masterly.NightShift.CoreJobs, client, server, states, filters, the dashboard and the source generator.
Masterly.NightShift.SqlServerSQL Server storage.
Masterly.NightShift.NetCoreDependency injection and hosted-service integration.
Masterly.NightShift.AspNetCoreDashboard middleware and endpoint mapping.

The libraries target netstandard2.0, net8.0 and net10.0.

Pre-release. The packages are not published to nuget.org yet. Until they are, build from the repository.

Minimal ASP.NET Core setup

Register the storage and the processing server, then map the dashboard.

using Masterly.NightShift;
using Masterly.NightShift.SqlServer;

var builder = WebApplication.CreateBuilder(args);

builder.Services.AddNightShift(config => config
    .SetDataCompatibilityLevel(CompatibilityLevel.Version_180)
    .UseSimpleAssemblyNameTypeSerializer()
    .UseSqlServerStorage(builder.Configuration.GetConnectionString("NightShift")));

builder.Services.AddNightShiftServer();

var app = builder.Build();

app.MapNightShiftDashboard();   // default path: /nightshift

app.Run();

By default the dashboard answers local requests only. See dashboard authorization before exposing it. The schema is created on first start unless you turn PrepareSchemaIfNecessary off in SqlServerStorageOptions.

Console or worker setup

Without ASP.NET Core, configure the global configuration and start a BackgroundJobServer. In a generic host, AddNightShift and AddNightShiftServer work the same way as above.

using Masterly.NightShift;
using Masterly.NightShift.SqlServer;

GlobalConfiguration.Configuration
    .SetDataCompatibilityLevel(CompatibilityLevel.Version_180)
    .UseSimpleAssemblyNameTypeSerializer()
    .UseSqlServerStorage(connectionString);

using (new BackgroundJobServer())
{
    Console.WriteLine("Server started. Press Enter to stop.");
    Console.ReadLine();
}

Several servers can read the same storage. Give each one its own queues with BackgroundJobServerOptions.Queues.

Enqueue jobs

A fire-and-forget job runs once, as soon as a worker is free. The call is an expression: the type, method and arguments are serialized into storage.

BackgroundJob.Enqueue(() => Console.WriteLine("Hello, world!"));

// Instance methods on a class resolved through your JobActivator / DI container
BackgroundJob.Enqueue<ReportService>(x => x.Build(42));

Enqueue returns the job id, or null when a client filter cancels the creation.

Recurring jobs

Recurring jobs are identified by name, so calling AddOrUpdate again on every start is safe. Use a CRON expression, a Cron helper or plain English.

RecurringJob.AddOrUpdate("minutely", () => Console.WriteLine("Hello"), Cron.Minutely);
RecurringJob.AddOrUpdate("nightly", () => Console.WriteLine("Cleanup"), "0 2 * * *");
RecurringJob.AddOrUpdate("digest", () => SendDigest(), Cron.FromText("weekdays at 7:30"));

Delayed jobs

Schedule a job for later with a delay, or with a phrase.

BackgroundJob.Schedule(() => SendReport(), TimeSpan.FromMinutes(30));
BackgroundJob.Schedule(() => SendReport(), "tomorrow at 9am");
BackgroundJob.Schedule(() => Cleanup(), "in 2 hours");

Continuations

Run a job after another one succeeds. Fan-in continuations wait for several parents.

string first = BackgroundJob.Enqueue(() => Download());
string second = BackgroundJob.ContinueJobWith(first, () => Parse());

// Fan-in: wait for several parents
BackgroundJob.ContinueJobWithAll(new[] { first, second }, () => Merge());
BackgroundJob.ContinueJobWithAny(new[] { first, second }, () => NotifyFirst());

Open the dashboard

Start the application and browse to /nightshift on the local machine, for example http://localhost:5000/nightshift. The Jobs, Recurring jobs, Servers and Queues pages show what you just created. Read more on the dashboard page.

To use another path, pass it to the mapping call: app.MapNightShiftDashboard("/jobs").
